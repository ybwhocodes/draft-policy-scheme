🛡️ Securing Financial Data

Arsitektur Keamanan Standard Bank (SNAP 1.0.8)

Sistem keamanan berlapis menjamin kerahasiaan data transaksi serta mencegah manipulasi angka tagihan di tengah jalan (Man-in-the-Middle Attack).

Modul Auth B2B /access-token/b2b

💼 Perspektif Direksi (Bisnis)

Seperti surat izin masuk gedung bertingkat yang harus diperbarui tiap 15 menit. Jika ada pihak tak dikenal mencuri token, token tersebut otomatis kadaluarsa sehingga kerugian finansial dapat dicegah.

💻 Perspektif Developer (Teknis)

Memanggil HTTP POST dengan Header X-CLIENT-KEY & X-SIGNATURE (SHA256withRSA dari string ClientID|Timestamp disandikan dengan Private Key Mitra). Menghasilkan Bearer JWT valid 900 detik.

Modul Integritas Pesan Header: X-SIGNATURE (HMAC)

💼 Perspektif Direksi (Bisnis)

Setiap instruksi transaksi disegel dengan stempel digital tak terlihat. Jika peretas mencoba mengedit nominal dari Rp 10.000 menjadi Rp 1.000, Bank Mandiri akan mendeteksi stempel rusak dan transaksi otomatis ditolak.

💻 Perspektif Developer (Teknis)

Setiap request transaksi menyertakan signature HMAC_SHA512 menggunakan Client Secret. Format String to Sign: Method:Url:Token:HexEncode(SHA256(Minify(Body))):Timestamp.

Kompleksitas & Overheads Keamanan API

Perbandingan beban komputasi dan enkripsi antar endpoint SNAP. Auth B2B memerlukan operasi RSA Asimetris yang berat namun berfrekuensi rendah (15 menit sekali).

RSA-256 (Asymmetric): Tinggi (High Security)
HMAC-SHA512 (Symmetric): Cepat (High Speed)

Detail Modul Alur Operasional Virtual Account

Proses real-time dua arah yang menghubungkan nasabah di channel Mandiri (Livin'/ATM) dengan server database mitra.

🔍 Langkah 1

1. Inquiry VA

POST /transfer-va/inquiry

💼 Bisnis Pelanggan mengetik nomor VA. Bank Mandiri bertindak sebagai kurir yang bertanya ke server mitra: "Berapa total yang harus dibayar?"
💻 Teknis Mandiri panggil API Inquiry. Sistem mitra wajib merespon dengan `totalAmount`, `virtualAccountName`, & `billDetails` dalam durasi < 2 detik.
RC Sukses: 2002400 | Code: 4042401 (Not Found)
💳 Langkah 2

2. Payment Request

POST /transfer-va/payment

💼 Bisnis Setelah pelanggan klik "Bayar" dan uang terpotong di bank, Mandiri mengabari mitra: "Uang sudah diterima, mohon laskan pesanan."
💻 Teknis Callback masuk ke server mitra. Simpan `referenceNo`, validasi `paidAmount`, dan update status transaksi di database internal.
RC Sukses: 2002500 | Forced OK: 5002500
🔄 Langkah 3

3. Inquiry Status

POST /transfer-va/status

💼 Bisnis Jika koneksi sempat terputus dan ragu apakah uang sudah masuk atau belum, mitra bisa menanyakan ulang status resmi pembayaran ke Mandiri.
💻 Teknis Mitra panggil API Status membawa `inquiryRequestId`. Mengembalikan status `00` (Sukses) atau `06` (Reversal/Gagal).
RC Sukses: 2002600 | Code: 4042601 (Not Found)

Alokasi Budget Toleransi Waktu (Latency Budget)

Proses Inquiry dan Payment Virtual Account memerlukan respon yang sangat cepat agar pelanggan tidak mengalami kebingungan (timeout) pada layar aplikasi perbankan.

● Target API < 1.5s ● Timeout Limit 5.0s
📊 Error Management & Standardized RC

Matriks Response Code (RC) SNAP Mandiri

Setiap transaksi mengembalikan Response Code 7 digit yang memetakan status keberhasilan, kesalahan format data, maupun masalah pada server.

Distribusi Kode Status Sistem

⚠️ Aturan Khusus Forced OK Mandiri

Jika server mitra mengalami error (RC 5002500 / 5002501) atau Time Out (RC 5042500) saat *Payment Request*, Bank Mandiri akan **tetap menganggap transaksi sukses (Forced OK)** karena uang nasabah sudah dipotong. Mitra WAJIB menyediakan mekanisme rekonsiliasi manual/otomatis.

HTTP Response Code Response Message Penjelasan Bisnis & Teknis
200 2002400 / 2002500 Successful Transaksi Inquiry / Payment berhasil diproses penuh.
400 4002401 / 4002501 Invalid Field Format Format data request salah (misal: tanggal tidak ISO-8601).
401 4017300 / 4012401 Unauthorized / Invalid Token Signature atau Access Token kadaluarsa / tidak sah.
404 4042401 Invalid Bill / VA Not Found Nomor VA tidak terdaftar pada database sistem mitra.
404 4042414 / 4042514 Paid Bill Tagihan ini sudah dilunasi sebelumnya.
409 4092400 / 4092500 Conflict Duplikasi X-EXTERNAL-ID dalam hari yang sama.
500 5002500 / 5002501 General Error / Biller Error Mandiri Forced OK: Terjadi error di mitra, uang tetap dipotong.
504 5042500 Time Out Mandiri Retry 1x: Jika tetap timeout, Mandiri akan Forced OK.
